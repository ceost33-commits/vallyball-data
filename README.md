# 🏐 V-리그 배트맨토토 배구 누적 데이터 허브

배트맨토토(프로토 승부식) 배구 경기 데이터를 자동으로 수집·축적하고, **남자부/여자부**, **구단별/전체(일정별 1게임씩 누계)**로 통계를 분석하는 반응형 대시보드 웹사이트입니다.

---

## 📁 디렉터리 구조
```
volleyball-betman-tracker/
├── index.html            # 메인 웹 대시보드 (반응형 웹, 단일 파일 실행 가능)
├── crawler.py            # 프로토 승부식 배구 경기 데이터 수집 및 축적 엔진
├── generate_html.py      # 대시보드 빌드 스크립트
├── update_data.py        # 시즌 경기 데이터 생성 및 시딩 스크립트
├── data/
│   └── matches.json      # 경기별 3대 배팅 유형(승패/핸디/언오버) 누적 데이터베이스
└── README.md             # 프로젝트 명세 및 사용 가이드
```

## 🎯 핵심 기능 및 화면 구성

### 1. 상단 리그 전환
- **👨 V-리그 남자부 (KOVO남)**: 한국전력, 현대캐피탈, 대한항공, 우리카드, KB손해보험, 삼성화재, OK저축은행 (7개 구단)
- **👩 V-리그 여자부 (KOVO여)**: 흥국생명, 한국도로공사, IBK기업은행, 정관장, GS칼텍스, 현대건설, 페퍼저축은행 (7개 구단)

### 2. 2대 보기 모드 (`구단별` / `전체`)
1. **🛡️ 구단별**:
   - `구단별` 버튼을 누르면 리그 7개 구단이 한눈에 보이는 **구단 선택 패널**이 펼쳐집니다.
   - 원하는 구단을 클릭하면 해당 구단의 최근 전적(예: 3승 1패)과 함께:
     - 구단 전용 통계 카드: 일반 승률, 세트 핸디 극복률, 오버/언더 비율, 경기당 평균 합산 득점
     - 해당 구단의 모든 경기 일정별 1게임씩 누적 히스토리를 확인 가능
2. **📅 전체 (일정별 1게임씩 누계)**:
   - 구단 패널은 숨겨지고 리그 전체 경기가 날짜/일정 순서대로 1게임씩 차례대로 누적(누계)되어 표시됩니다.
   - **누계 #**: 시즌 1호기부터 최신 경기까지 순차 번호 부여 (`#1` ~ `#16`)
   - **누계 흐름**: 해당 경기 시점까지의 러닝 정배율(%) 및 오버율(%)을 각 행마다 자동 산출
   - **뷰 전환**: `📋 누계 테이블 표`(엑셀 스프레드시트 뷰) 및 `🃏 상세 카드` 뷰 1클릭 전환 지원
   - **정렬 옵션**: `⬇️ 최신 일정순` 및 `⬆️ 개막 순차순` 지원

### 3. 경기당 3종류 배트맨 데이터 완벽 축적
한 경기 안에서 프로토 승부식의 3대 핵심 유형이 1게임씩 누계됩니다:
1. **[1] 일반 승·패**: 홈 배당 vs 원정 배당 ➡️ 경기 결과, 정배/역배 판정, 적중 배당률
2. **[2] 세트 핸디캡**: 핸디 기준점(예: -1.5, +1.5) ➡️ 홈/원정 배당 ➡️ 마핸승/플핸승 판정
3. **[3] 총득점 언더/오버**: 기준점(예: 181.5) ➡️ 오버/언더 배당 ➡️ 양팀 최종 합산 점수 및 오버/언더 판정

## 🚀 실행 및 데이터 업데이트 방법

### 1. 대시보드 열람
- `volleyball-betman-tracker/index.html` 파일을 웹 브라우저(크롬, 사파리, 엣지 등)로 더블클릭하거나 드래그하여 열면 별도 웹서버나 인터넷 연결 없이도 즉시 모든 통계와 필터가 작동합니다.

### 2. 데이터 동기화 및 대시보드 갱신
```bash
python3 volleyball-betman-tracker/crawler.py
```
- 위 명령어를 실행하면 `data/matches.json`의 누적 통계 현황 요약이 출력되고, 최신 데이터가 반영된 `index.html` 파일이 자동으로 재빌드됩니다.
